# Muhamad Nurul Bayan_Algoritma_pemograman
Tugas Algoritma Pemograman

## Menentukan Bilangan Genap atau Ganjil

## A. Deskripsi Masalah

Program sederhana berbasis Python untuk menerapkan konsep logika matematika dalam menentukan apakah suatu bilangan termasuk bilangan genap atau ganjil. Program menerima input berupa bilangan bulat, kemudian menggunakan operasi modulo untuk mengevaluasi kondisi dan menghasilkan output yang sesuai. Proyek ini dilengkapi dengan pseudocode, flowchart, serta pengujian menggunakan beberapa test case sebagai implementasi dasar struktur percabangan (if-else).
